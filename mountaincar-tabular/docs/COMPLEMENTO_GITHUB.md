# Publicação do código local e das figuras originais

A branch contém o **notebook Colab executável**, os **108 resumos por execução** (cópia comprimida sem hashes), duas figuras SVG vetoriais, tabelas selecionadas, auditoria e apresentação.

O complemento produzido na conversa, denominado `CMP629_COMPLEMENTO_GITHUB.zip`, adiciona:
- os **sete arquivos-fonte/configuração** recebidos para auditoria (snapshot parcial; não um projeto local completo);
- o CSV original com 108 hashes de configuração;
- as **quatro figuras originais** da triagem em PNG e PDF (oito arquivos);
- os demais relatórios de análise, dados e testes independentes.

Esses arquivos binários e o código original **não foram inseridos automaticamente pelo conector** e devem ser enviados pelo script `PUBLICAR_COMPLEMENTO_GITHUB.ps1` incluído no ZIP, após extrair seu conteúdo no Windows. Não anunciar o repositório como integral enquanto esse complemento não for enviado.

Este diretório evita publicar PDFs didáticos de terceiros, documentos pessoais e material da dissertação.

A fonte científica do estado atual é a auditoria de 11/10/2026, em `AUDITORIA.md`. Não executar o experimento final antes das correções P0/P1 e dos testes de invariantes.
